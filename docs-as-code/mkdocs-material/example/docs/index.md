# Example Docs Portal

A small Material for MkDocs site that exercises the features covered in the tutorial.
Every page here is a working example you can copy.

- [Code examples](code-examples.md): highlighting, titles, line numbers, highlighted lines
- [Content tabs](content-tabs.md): tabbed text and tabbed code
- [Admonitions](admonitions.md): callouts, including collapsible ones
- [Diagrams](diagram-examples.md): Mermaid flowcharts and sequence diagrams

Emoji and icons work inline once the `pymdownx.emoji` extension is on:
I like to drink :beer: after I have played :soccer:. Icons from the bundled sets
render the same way: :material-check-circle: :fontawesome-brands-github:.
