# Admonitions

Admonitions (callouts) draw attention to a block. Three exclamation marks make a fixed
block, three question marks make a collapsible one (`???+` starts expanded).

!!! note "Title of the callout"

    Text of the note. Anything indented under the marker is part of the block.

??? info "Collapsible callout"

    Hidden until the reader opens it. Useful for long detail that most people skip.

!!! warning

    A warning without a custom title uses the type name as its title.

Types that ship with Material: `note`, `abstract`, `info`, `tip`, `success`, `question`,
`warning`, `failure`, `danger`, `bug`, `example`, `quote`.
