# Content tabs

Tabs group alternatives so the reader picks one. Plain text first:

=== "Plain text"

    This is some plain text.

=== "Unordered list"

    - First item
    - Second item
    - Third item

=== "Ordered list"

    1. First item
    2. Second item
    3. Third item

The same thing with code, the usual case for multi-language examples:

=== "Python"

    ```py
    def main():
        print("Hello world!")


    if __name__ == "__main__":
        main()
    ```

=== "JavaScript"

    ```js
    function main() {
      console.log("Hello world!");
    }

    main();
    ```
